# marketing-os

Monorepo (pnpm workspaces) containing:

- `apps/website` — public marketing site, built with Next.js + Three.js (`@react-three/fiber`, `@react-three/drei`, `@designcodeio/threeui`).
- `apps/dashboard` — internal/marketing dashboard, built with Next.js + shadcn/ui. (scaffolded later)

## Commands

```bash
pnpm install
pnpm dev:website
pnpm dev:dashboard
```
